## Parallel Product Search

Run a simple product search using the Parallel Python SDK.

### 1) Create and activate a virtual environment (macOS/Linux)

If you don't already have one:

```bash
python3 -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

### 2) Install dependencies

```bash
pip install -r requirements.txt
```

### 3) Set Parallel API key environment variable

```bash
export PARALLEL_API_KEY="your_api_key_here"
```

### 4) Run the script

```bash
python product_search.py --query "black couch"
```
